# FSL test fixtures

The NIfTI fixtures in this directory are taken, unmodified, from the
`fslpy` project's test data (`fsl/tests/test_transform/testdata/nonlinear`):

- `coefficientfield.nii.gz` — a FNIRT cubic B-spline coefficient field.
- `displacementfield.nii.gz` — a FNIRT dense deformation field.
- `ref.nii.gz` — the reference image the warps were computed against.
- `src.nii.gz` — the moving (source) image the warps map to.
