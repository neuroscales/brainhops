# Metadata for format authors

The public names of [`brainhops.datamodel.metadata`](metadata.md) and
[`brainhops.io.metadata`](../io/metadata.md) are those that a user of
the library needs. The names below are for whoever adds the vocabulary
to the metadata of a file format, and the
[format author's guide](../../dev/metadata-formats.md) explains how they
fit together. They are imported from the private modules that define
them.
